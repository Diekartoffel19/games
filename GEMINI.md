# Antigravity / Gemini Agent Guidelines

See [AGENTS.md](AGENTS.md) for full guidelines.

## Branching Requirement
- **New Games**: Create new branch (`feat/<game-name>`). Do not commit to `main`.
- **Big Bug Fixes**: Create new branch (`fix/<bug-name>`). Do not commit to `main`.

## Tool Usage
- **Gemini strengths**: Take on tasks where Gemini is stronger directly (image/sprite/texture generation, visual analysis, large-context reads, Google-grounded research).
- **Blender**: Before creating or editing 3D models, textures or scenes, ask the user whether Blender should be used. Do not start Blender without confirmation.
