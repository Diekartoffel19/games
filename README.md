- **[`games/survivor.html`](games/survivor.html)**: Crypt Survivor: Rogue Dawn (Bullet-Heaven Roguelite)
- **[`games/spire.html`](games/spire.html)**: Spire of Cards (Roguelike Deckbuilder)
- **[`games/neondefense.html`](games/neondefense.html)**: Cyber Defense: Neon Grid (Sci-Fi Tower Defense mit Tech-Tree)
- **[`style.css`](style.css)**: Globales Stylesheet für Hub, Navigation und Touch-Controls
