How to

Click atom: select. Shift+click: multi-select.
Add atom: new atom of chosen element bonded to selection (or alone).
Bond ⟳: with 2 selected, cycles none→single→double→triple.
Element button with atoms selected: changes their element.
Fill H: satisfies valence. Optimize: relaxes geometry (bond lengths from covalent radii, VSEPR angles).
Select 2 atoms: distance. 3: angle. 4: dihedral.
Keys: Del = delete, A = add, B = bond, H = fill H, O = optimize.
