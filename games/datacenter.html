⬆️ Upgrades

🖥️ Datacenter Tycoon 3D

Vom Garagen-Hoster zum Hyperscaler.

  • Racks aufstellen und Server einbauen – jeder laufende Server bringt Geld pro Sekunde.
  • Verkabeln: 🔴 Stromkabel Rack/Switch/Klima → ⚡ PDU → 🏭 Hauptverteiler. 🔵 Netzkabel Rack → 🔀 Switch → 🌐 Uplink-Router.
  • Kühlung: Volle Racks werden heiß. Ab 60 °C schalten sie ab – ❄️ Klimageräte in der Nähe aufstellen.
  • Engpässe: PDUs und Hausanschluss haben kW-Grenzen, Kupferkabel nur 10 Gbit/s, der Uplink ist begrenzt.
  • Upgrades: Server (CPU/RAM/GPU/KI), Rack-Ausbau bis Flüssigkühlung, Switch-Ports, PDU-Leistung, Klima-Stufen, Glasfaser, Hallen-Erweiterung, Solar-Dach, USV, DDoS-Schutz …
  • 🎯 Ziele: Erfülle Aufträge (links oben) für Geld-Belohnungen.

Maus: Linksklick = bauen/auswählen · Ziehen = drehen · Rechts-/Mittelklick-Ziehen = verschieben · Mausrad = Zoom · WASD = Kamera · R = drehen · Tasten 1–9 = Werkzeuge · H = Wärmekarte · U = Upgrades · G = Tempo 1×/2×/4× · Esc = abbrechen. Touch: Tippen = bauen, Ziehen = drehen, zwei Finger = zoomen/verschieben.
