# Debug- & Test-Skripte

Diese Skripte dienten temporären Tests und visuellen Inspektionen via Headless Chrome (z. B. Pixel-Auslesen und Canvas-Projektionstests für `games/elpatron.html`).

Sie sind **kein** Bestandteil der Spiele selbst und werden für den normalen Spielbetrieb nicht benötigt. Falls nicht mehr benötigt, kann dieser Ordner jederzeit gelöscht werden.
